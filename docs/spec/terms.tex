\chapter{Terms and Definitions}

\section{Words}
The things defined here will never be referred to any other way, but the way they are defined.


\para{evaluate} 
\subpara Determine the value of an expression.
    
\para{expression} 
\subpara A construct that, when evaluated, produces a value and/or side effects.
    
\para{place} 
\subpara A physical or abstract location a valid value exists in.

\para{result type} 
\subpara The type that an expression evaluates to.
    
\para{result value}
\subpara The value that an expression evaluates to.
    
\para{statement} 
\subpara A syntatic construct that specifies an action or controls the execution flow of a program.

\para{value} 
\subpara A temporary result of an expression. Temporaries are destroyed as soon as they are not needed anymore.
    


\section{Punctuator}


\para The term \textit{arrow} refers to the following few symbols.
\subpara[Left Dash Arrow] \texttt{->}
\subpara[Right Dash Arrow] \texttt{<-}

\para The term \textit{braces} refers to the following two symbols:
\subpara[Left brace] \texttt{\{}
\subpara[Right brace] \texttt{\}}

\para The term \textit{brackets} refers to the following two symbols:
\subpara[Left bracket] \texttt{[}
\subpara[Right bracket] \texttt{]}

\needspace{5\baselineskip}
\para The term \textit{chevrons} refers to the following two symbols:
\subpara[Left chevron] \texttt{<}
\subpara[Right chevron] \texttt{>}
