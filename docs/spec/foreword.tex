

\introduction
\para This document defines how any implementation of Cinnabar has to work. If a compiler does not follow the rules defined in this document, it is non compliant and should be used with care.

\para The Cinnabar language is a AOT-compiled language that specializes in non-prescriptive abstractions. That is abstractions that don't take away control from you, the developer. It has some unrestricted escape hatches in ways that C++ does not. Using higher level constructs may conceal behavior, however one of the core philosophies is that you can always touch them. It is about abstraction without surrendering control.


\para Also see \crucible for the build system, as this is only the language specification.
