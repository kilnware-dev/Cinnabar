\section{Introduction}

Hello! This is my first specification. I would be extremly happy if you gave me any feedback on literally anything. These are also my first \LaTeX\ documents.

Cinnabar is a compiled language inspired by C++. It tries to create an enviroment that is similar to C++ in many ways, but with many improvements made.

The goal is to create a language that will make native applications great again. Right now Rust is probably the best thing for native apps, but I have some issues with Rust. Like the reliance on built-ins for eg. error handling, although it is slowly being fixed.

This is not my first time creating a language, however the first time I am using zero AI. More on that in the next section.

\bigskip
Improvements include but are not limited to:

\para[Better Defaults] eg. explicit / nodiscard by default
\para[Better Moves] eg. destructive moves / no implicit copy 
\para[Zero-Cost Safety] eg. bounds checking eliminated when provable
\para[Built-In Error handling] I don't know how this will work yet. It is a work in progress.
