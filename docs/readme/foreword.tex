\section{About Cinnabar}
\para Cinnabar is a statically typed language compiled, general purpose programming language with a focus on applications and games. It supports low level operation such as direct pointer manipulation and raw memory allocation.

\para The goal with Cinnabar is to fix C++'s decades of baggage. There should be a single way to initialize a variable. There should not be a most vexing parse. I aim to improve the bad defaults by making functions nodiscard by default, and requiring an implicit keyword, instead of explicit.

\para There is also no implicit copying, implicit referencing unless you define it. Cinnabar also gives you access to some language facilities that are genuinely missing from C++. Such as \verb|abandon $foo;|

\para This syntax allows for the suppression of the destructor, which allows for some things C++ only gets through optimization to be direct language features.

My compiler follows a front-end/middle-end/back-end architecture. By default the back-end is LLVM, although this may be customizable in the future.
